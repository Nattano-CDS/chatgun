# rc4 → rc5 material changes

| Area | rc4 | rc5 correction |
|---|---|---|
| Human model | Two distinct consenting adults A/B | One verified adult owner operating two personally controlled identities/devices |
| Evidence label | Genuine two-participant UAT | Single-operator dual-account functional E2E; independent two-human cases are BLOCKED/NOT RUN |
| Consent | Separate human consent attributed to A and B | One truthful owner authorization covering operator scope and each owned identity; no independent B-human claim |
| Admission | Two-person allowlist | Exactly two identity slots: A=LINE, B=Google; unique provider, private-reference hash, user and provider-subject bindings |
| Invitations | Participant A/B | Initial-enrollment identity A/B invitations, provider-bound and single use |
| Deletion | Separate Participant B consent | Separate owner YES/NO for deletion of ChatGun UAT Google identity/account B only, after de-enrollment/session revocation |
| External accounts | Ambiguous participant account language | External Google/LINE accounts and Production LINE identity are explicitly outside deletion authority |
| Functional coverage | Could be read as two-human interaction evidence | Profile/Discovery/Chat/Presence/privacy across two devices are functional tests by one operator |
| Unchanged | 24/7 private access; 19:00–22:00 moderation; seven-day logical cleanup; 90-day minimized audit; backup limitations; safety restrictions | Same, now attached to the truthful operator/identity model |

rc4 files and hashes remain preserved as historical drafts. rc5 is not approved by the earlier rc4 decision.
