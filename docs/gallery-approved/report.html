Implementation and resolved defects

  • Four dedicated routes and explicit server photo scopes; no mixed Public/Private photo response or cross-album post navigation.
  • Approved prototype CSS and exact SVG glyphs; existing ChatGun logo and original NEAR navigation retained. Content-dependent counts differ intentionally from prototype samples.
  • Public Gallery does not reuse an owner's private selected photo as its avatar. Returning from either album refreshes the Profile public-photo count.
  • Responsive lightbox no longer sits beneath navigation; keyboard focus is contained. Cancelling a media report returns to the same photo.
  • Multi-file previews, removal, optional captions, progress, retry/idempotency and Pending Moderation. Independent Chat quota and shared Public/Private Gallery quota remain enforced. Upload attempts also have a separate abuse limit.
  • Additive D1 capacity trigger closes concurrent 12-photo bypass. Failed commits release quota and queue R2 cleanup if immediate deletion fails.
  • Versioned fictional fixtures and optional confirmation-only batch reset in Demo Chat; no automatic reset or expiry and no deletion of uploaded files, original data or daily quota.

Safety and data preservation

  • Production is browser-only fiction. Demo permissions are simulations, never credentials for private real-member media. Illustrations and existing fictional portraits are public demonstration assets, not confidential R2 objects.
  • Real authentication, registration, social services, uploads, moderation tools and Sensitive Content remain disabled. Production R2 is unbound; no Production migrations or member mutations.
  • Isolated D1/R2 HTTP and browser tests exercise server authorization independently of the demo. Public photo queries default to Public scope even for granted viewers. Private requests, comments, bytes and navigation are checked by the backend.
  • Migration 0014 is additive, isolated-staging-only, and atomically enforces the combined 12-photo capacity. The existing independent Chat/Gallery daily quota, Bangkok reset, CSRF, sessions, sanitization and manual moderation remain.
  • Fixture batch chatgun-gallery-approved-v1 is additive and browser-persistent. It preserves the original 20 members/120 messages and existing edits; no automatic expiry, reset or reinsertion of deleted new fixtures. Existing full galleries are not overwritten to make space.
  • Rollback: restore the previous successful Pages deployment recorded in package-check.json. No database rollback is needed for this fictional Production release. Leave the additive isolated trigger in place.

Live-service blockers remain separate

No approval is claimed for real-user launch. Real services still require their outstanding operational/legal readiness gates, approved moderation/scanning and age/location safeguards, Production migrations with separate authorization, and a separately validated provider-enabled release. OAuth/CAPTCHA was not re-run for this Gallery change.
