คุณทดสอบต่อได้

  1. เปิด chatgun.social ใน Chrome ที่ใช้บัญชีเจ้าของเดิม หากระบบขอ login ให้ทำ Turnstile และ LINE ด้วยตนเอง ไม่ต้องใช้ invitation ใหม่
  2. ตรวจ Profile, Account/Privacy/Session controls และ Admin Dashboard ตามสิทธิ์เดิม การเปิด restricted queues อาจต้อง recent authentication ตามปกติ ไม่ได้ลบข้อกำหนดนี้
  3. ทดสอบ logout/login ซ้ำเมื่อพร้อม บันทึกผลที่พบเพื่อแก้รวม ไม่ลบบัญชีเจ้าของในการ UAT

ยังไม่ทดสอบ genuine OAuth/Session ในรุ่นนี้แทนเจ้าของ ไม่มีการคลิก CAPTCHA/ใส่รหัสผ่าน/MFA/consent หรือสร้างบัญชีจริงอัตโนมัติ
