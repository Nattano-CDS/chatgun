แผน Full-System E2E/UAT รอบเดียว

เอกสารเตรียมการทางเทคนิค ไม่ใช่การเปิด Beta หรือคำขอให้เจ้าของเข้าสู่ระบบระหว่างพัฒนา ไม่ออกคำเชิญ ไม่ให้สิทธิ์จริง และไม่ถือว่า automated fixtures คือผู้ทดสอบมนุษย์

สภาพแวดล้อมและสิ่งที่ต้องอนุมัติก่อนเริ่ม

Candidate: isolated stable Preview · D1 chatgun-issue13-staging (275d9820-6aec-494a-8bb5-b7ed9b8b74cc) migrations 0001–0017 · private R2 chatgun-issue13-media ไม่ใช่ Production หรือฐาน fixture Staging เดิม

ปัจจุบัน Preview นี้ปิด OAuth และการรับสมัครสำหรับการทดสอบอัตโนมัติ ต้องตั้งค่าบัญชีผู้พัฒนา/credentials สำหรับ Preview ที่ถูกต้อง และ Turnstile hostname/key pair ก่อน UAT จริง ห้ามคัดลอก Production secrets มาใช้ ห้ามใช้ fixture session แทน genuine login

  • ผู้ใหญ่ที่ยินยอมอย่างน้อยสองคนที่ได้รับอนุมัติรายบุคคล มีผู้ตรวจอุทธรณ์คนอื่นที่ได้รับอนุมัติบทบาทหากทดสอบ independent review ไม่แต่งตั้งโดยอัตโนมัติ
  • ยืนยัน eligibility ตามขอบเขต pilot ที่อนุมัติ ไม่ถือว่า checkbox 18+ คือการยืนยันอายุอิสระ
  • อนุมัติขอบเขตนโยบาย Social/ตำแหน่ง/สื่อ การทดสอบลบบัญชีที่ไม่ใช่เจ้าของ และช่องทางเหตุฉุกเฉิน/อุทธรณ์ก่อนเปิด flag สำหรับ genuine participants
  • ยืนยันบัญชี Admin ผ่าน session จริงและ UUID ส่วนตัวก่อนให้สิทธิ์ Staging แยกจาก Production ห้ามถ่ายโอน cookie/session หรือปลอมเป็นบัญชีเจ้าของ Production
  • Production grant ปัจจุบันหมดอายุ 27 ตุลาคม 2026 เวลา 11:01:45 Asia/Bangkok ห้ามขยายเงียบ ๆ
  • คง public signup, Sensitive, identity-document upload, OTP, Game และ Demo ปิด ไม่มีคำเชิญจริงก่อนอนุมัติผู้รับ

ใช้ BETA_ENROLLMENT_REQUIRED=true ใน isolated testing และตรวจ active enrollment เฉพาะ actors ที่ได้รับอนุมัติ ระบบจะปฏิเสธการเข้าถึง/ค้นหา/ติดต่อ/เปิดสื่อของบัญชีเก่าที่ไม่ได้รับสิทธิ์ ไม่ต้องลบ fixture เดิม เมื่อ genuine UAT ได้รับอนุมัติ ให้ตรวจ enrollment รายคนอีกครั้ง ไม่เปลี่ยน Production flag นี้หรือกติกาสมาชิกเดิมโดยอัตโนมัติ ค่าเริ่มต้นของโค้ดยังปิดไว้

OAuth / Turnstile ที่ต้องจัดเตรียม

ใช้เฉพาะ Preview application/channel ที่ได้รับอนุมัติ เพิ่ม URL เหล่านี้โดยไม่ลบ callback เดิม และ allowlist hostname ใน Preview Turnstile:

  • Google: https://issue13.chatgun-issue13-staging.pages.dev/api/auth/oauth/google/callback
  • Facebook: https://issue13.chatgun-issue13-staging.pages.dev/api/auth/oauth/facebook/callback
  • LINE: https://issue13.chatgun-issue13-staging.pages.dev/api/auth/oauth/line/callback

required Preview keys: GOOGLE_CLIENT_ID/SECRET, FACEBOOK_CLIENT_ID/SECRET, LINE_CLIENT_ID/SECRET, TURNSTILE_SITE_KEY/SECRET_KEY และ provider allowlist ตามที่อนุมัติ เก็บ secret ผ่าน encrypted Pages Preview configuration เท่านั้น ไม่ใส่ Git/รายงาน/แชท ไม่ publish provider apps โดยอัตโนมัติ

Flags และข้อมูลสำหรับ genuine UAT หลังอนุมัติเท่านั้น

ไม่ใช้ค่า fixture config ทั้งชุดเป็น genuine admission config และไม่เปลี่ยนค่าเหล่านี้ใน Production ระหว่างเตรียม

กลุ่มค่าที่ต้องตรวจ

ใช้บัญชีจริงที่ผู้ร่วมทดสอบยินยอม บันทึก ID/ผู้รับคำเชิญ/role grant ใน handoff ส่วนตัว ไม่แนบในรายงานสาธารณะ ใช้รูปทดสอบที่เจ้าของยินยอมและไม่มีข้อมูลส่วนตัวเกินจำเป็น ไม่ปลอม OAuth subject หรือย้าย session จาก Production

หลักฐานและการกู้คืน

บันทึก PASS/FAIL/BLOCKED/SKIP รายกรณี พร้อม SHA/environment/time เฉพาะข้อมูลที่จำเป็น ไม่เผย token, invitation URL, OAuth code, UUID ของบุคคลจริง หรือภาพส่วนตัวใน GitHub หากพบข้อบกพร่อง รวมแก้และทดสอบส่วนที่กระทบกับ regression suite ก่อนขอ rollout approval

หากล้มเหลว ปิด capability ที่เกี่ยวข้อง รักษาบัญชี/ข้อมูลจริง ไม่ reset D1/R2 ไม่ทิ้งรูปหรือข้อความเพื่อให้ test ผ่าน ห้าม restore backup ทับข้อมูลใหม่โดยไม่มีอนุมัติแยก UAT ไม่ใช่คำสั่ง deploy Production
