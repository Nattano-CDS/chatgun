# ChatGun

ChatGun is a responsive social-network landing and signup experience hosted on Cloudflare Pages. Authentication is implemented with Pages Functions and D1 for Google, Facebook, LINE, and email OTP; SMS OTP remains disabled.

Run the local security and migration suite with `npm test`. Read [CLOUDFLARE_AUTH.md](./CLOUDFLARE_AUTH.md) before configuring or deploying Cloudflare resources.
