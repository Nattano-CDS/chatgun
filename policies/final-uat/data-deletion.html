กลับไปเข้าสู่ระบบ UAT

ขั้นตอนการปิดบัญชีและลบข้อมูล ChatGun Social UAT

เอกสาร UAT เฉพาะแคมเปญ — มีผลเฉพาะเมื่อเจ้าของอนุมัติ bytes/SHA-256 นี้และระบบผ่านการเปิดใช้อย่างมีการควบคุม · deletion-social-uat-2026-10-28-rc3

ขั้นตอนนี้ใช้เฉพาะสภาพแวดล้อม UAT แบบแยกและข้อมูลจาก Participant A และ B ซึ่งเป็นผู้ใหญ่คนละคน อายุ 20 ปีขึ้นไป ไม่เปลี่ยนขั้นตอนหรือข้อมูล Production ข้อเสนอ “เจ็ดวัน” หมายถึง logical cleanup ของข้อมูลสดหลังปิดแคมเปญ ไม่ใช่การรับประกันลบ backup ทางกายภาพ

1. เมื่อปิดแคมเปญ

  1. ปิด feature gate Social/Discovery/Chat/Presence ของ UAT และคง Media, public registration, youth, Sensitive Content, OTP และ Demo ปิดอยู่
  2. เพิกถอนคำเชิญที่เหลือ ปิด enrollment และเพิกถอน provider-linked sessions/คุกกี้ของแคมเปญ การเพิกถอนเซสชันไม่ลบบัญชี Google, Facebook หรือ LINE
  3. บันทึกเวลาปิด ขอบเขต รุ่น/แฮชเอกสาร การตัดสินใจ retention และผลการ cleanup โดยไม่บันทึก account reference ดิบในรายงานสาธารณะ
  4. ดำเนิน logical cleanup ที่ได้รับอนุมัติให้เสร็จภายในเจ็ดวันหลังเวลาปิด และติดตามงานที่ล้มเหลวจนสำเร็จหรือยกระดับต่อเจ้าของ

2. Participant A

ห้ามลบบัญชีจริงของ Participant A อัตโนมัติ ระบบต้องปิดสิทธิ์ UAT และเพิกถอนเซสชันที่เกี่ยวข้อง ลบข้อมูลแคมเปญที่แยกได้ตามแผน เช่น ตำแหน่ง Discovery, presence lease และข้อมูลทดสอบที่กำหนด โดยคงบัญชี/identity ตามที่เจ้าของอนุมัติ การดำเนินการใดที่เสี่ยง cascade ลบบัญชี A ต้องหยุดและต้องมีคำสั่งแยกต่างหาก

3. Participant B

การลบบัญชี UAT แบบทำลายของ Participant B ต้องมีความยินยอมแยก ชัดแจ้ง และบันทึกไว้จาก B หาก B ยินยอม ระบบจึงลบบัญชีและข้อมูลที่ผูกกับบัญชีตามความสัมพันธ์ D1 ที่ตรวจสอบแล้ว หาก B ปฏิเสธหรือยังไม่ตอบ ให้ปิดสิทธิ์/เพิกถอนเซสชันและ cleanup ข้อมูลแคมเปญที่ได้รับอนุมัติเท่านั้น ห้ามตีความความยินยอม Social หรือการถอน OAuth ว่าเป็นความยินยอมลบบัญชี

4. ข้อมูล D1 ที่ลบหรือคงไว้

สำหรับบัญชีที่อนุญาตให้ลบ งาน D1 ต้องจัดการ users/profile, provider identities, sessions, acceptance/lifecycle data, ตำแหน่งและ Discovery, Direct Chat/read state, presence preferences/leases, block/report และข้อมูล Social อื่นที่อ้างถึงบัญชี โดยใช้ transaction/cascade ที่ schema รองรับและตรวจ foreign-key หลังงาน สำหรับ Participant A หรือ B ที่ไม่อนุญาตลบบัญชี ให้ลบเฉพาะระเบียนแคมเปญที่แยกและอนุมัติไว้ พร้อมคงบัญชี/identity ที่ห้ามลบ

คงเฉพาะหลักฐานความปลอดภัย/ตรวจสอบขั้นต่ำที่จำเป็นอย่างเคร่งครัด เช่น digest เวลาและรุ่นการยอมรับ เหตุการณ์คำเชิญ/ป้องกัน abuse และผลการลบ เป็นเวลา 90 วันนับจากเวลาปิดแคมเปญจริง ต้องจำกัดการเข้าถึง ไม่ใช้เพื่อให้บริการ Social ต่อ และไม่เก็บ Chat เต็ม พิกัด บัญชีอ้างอิงดิบ credential สื่อ หรือโปรไฟล์ไว้ภายใต้ข้อยกเว้นนี้ เมื่อครบกำหนด Worker UAT ต้องลบหลักฐานสดที่หมดอายุหรือทำให้ไม่สามารถระบุตัวได้ และบันทึกผลโดยไม่อ้างการลบ backup ทางกายภาพ ข้อยกเว้นอื่นต้องมีฐานและระยะจำกัดที่บันทึกชัดเจน

5. D1 retries และการตรวจผล

แต่ละขั้นบันทึกสถานะและจำนวนที่คาดหมาย หาก transaction, cascade, foreign-key check หรือคำสั่งล้มเหลว งานยังถือว่าไม่เสร็จและต้อง retry แบบมีขอบเขตโดยไม่ลบ A หรือข้อมูลนอกแคมเปญ เมื่อ retry ไม่สำเร็จต้องหยุดการเปิด UAT ต่อ เก็บหลักฐานข้อผิดพลาดขั้นต่ำ และยกระดับต่อเจ้าของ ไม่ควรรายงาน PASS จนจำนวนแถวและ foreign-key ตรงเกณฑ์ที่กำหนด

6. R2 cleanup และ retries

Media ปิดตลอดแคมเปญ จึงไม่ควรมี upload หรือวัตถุสื่อ UAT ใหม่ และไม่มีงาน media moderation ที่อนุญาต หากการตรวจพบวัตถุ R2 ที่ไม่คาดหมาย ต้องถือเป็น defect/เหตุการณ์ความปลอดภัย ระบุเจ้าของและขอบเขตก่อนลบ แล้วใช้คิว cleanup ที่บันทึกสถานะและ retry จนยืนยันว่า object ที่กำหนดหายไป ห้ามลบ bucket หรือวัตถุที่ระบุที่มาไม่ได้ และห้ามอ้างว่ากลไก R2 ใดทำงานแล้วหากยังไม่ได้ตรวจจริง

7. Backup, Time Travel และการกู้คืน

Cloudflare backup, D1 Time Travel และสำเนากู้คืนอาจมีข้อมูลก่อน logical deletion ต่อไปตามความสามารถ/วงจรของผู้ให้บริการ และอาจไม่รองรับการลบรายแถว การเสร็จภายในเจ็ดวันและการหมดอายุหลักฐานสดที่ 90 วันจึงไม่แปลว่าสำเนาทุกชุดถูกลบทางกายภาพในกรอบเดียวกัน หากกู้คืน snapshot ต้องใช้ข้อจำกัดเดิม ทำ cleanup ซ้ำก่อนใช้ และห้ามนำข้อมูลที่ควรลบกลับมาให้บริการ Social

8. หลักฐานปิดงาน

รายงานสุดท้ายต้องระบุเวลาปิด งาน D1/R2 และ retry ที่ทำ จำนวนก่อน/หลัง ผล foreign-key สถานะเซสชัน ข้อยกเว้น backup/Time Travel และข้อมูลที่คงพร้อมเหตุผล โดยไม่เผย account reference, token หรือ credential ต่อ GitHub การลบถือว่า BLOCKED หากขาดความยินยอม B สำหรับการลบบัญชี พบวัตถุไม่ทราบที่มา หรือยืนยันผลไม่ได้
