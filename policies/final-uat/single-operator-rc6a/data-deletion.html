การปิดและลบข้อมูล Single-Operator Dual-Account Private UAT

Private UAT เท่านั้น — มีผลเฉพาะเมื่อบันทึก owner approval ของ exact bytes/SHA-256 นี้ครบถ้วน — มีผลหลังอนุมัติ exact bytes/SHA-256 และ owner authorization ที่เกี่ยวข้อง · deletion-social-friends-single-operator-dual-account-uat-2026-10-30-rc6a

1. เหตุเริ่ม

ไม่มี automatic 22:00 shutdown Cleanup เริ่มจาก actual explicit owner close, withdrawal/revocation ของ identity, หรือ safety shutdown ที่บันทึกจริง ระบบไม่เก็บ raw account reference/token ในหลักฐาน

2. ปิดการเข้าถึงก่อน

ปิด Social/Discovery/Chat/Presence และ enrollment ตามขอบเขต เพิกถอนคำเชิญ sessions และ A/B allowlist ตรวจว่ามีผู้ปฏิบัติการหนึ่งคน สอง identity เท่านั้น และ provider subjects ของ LINE/Google ต่างกัน คง Media/Gallery, public/youth, Sensitive, OTP, Demo, Admin และ Production ปิด

3. Logical cleanup ภายในเจ็ดวัน

ลบหรือทำให้พ้นการใช้งาน profiles, approximate location/Discovery, friend requests/friendship state, Chat/read state, Presence, block/report และ disposable lifecycle data ตาม schema ที่ตรวจสอบ ใช้ D1 transaction/cascade, bounded retries, counts และ foreign-key check ห้ามรายงาน PASS จนตรวจครบ Identity A และบัญชี Production LINE ห้ามลบอัตโนมัติ Identity B ลบได้เฉพาะ ChatGun UAT Google identity เมื่อมี owner authorization แยก และหลัง de-enrollment/session revocation เท่านั้น การลบ ChatGun ไม่ลบ external Google account

4. R2 และ retries

R2 private และ Media ปิด จึงไม่ควรมีวัตถุใหม่ หากพบให้หยุด ระบุ provenance และใช้ bounded cleanup/retry โดยไม่ลบ bucket หรือวัตถุที่ไม่ทราบที่มา D1/R2 failure ต้อง retry หรือยกระดับ ไม่แสดงผลสำเร็จเท็จ

5. หลักฐาน 90 วัน

เก็บเฉพาะ policy/version/hash, owner consent/close digest, invitation replay/security events และ cleanup result ที่ลดรูปและจำเป็นอย่างเคร่งครัด 90 วันจาก actual close ไม่เก็บ full Chat, location, raw account reference, credential, Media หรือ profile เพื่อ audit เมื่อหมดอายุ Worker ลบหลักฐานสดตามกลไกที่ตรวจสอบ

6. Backup/Time Travel

Cloudflare D1 Time Travel, backup และ recovery copy อาจอยู่นานกว่า logical cleanup และอาจลบรายแถวไม่ได้ เจ็ดวัน/90 วันไม่ใช่คำมั่น physical erasure หากกู้คืนต้องใช้ข้อจำกัดเดิมและ cleanup ซ้ำก่อนให้บริการ

7. ขอบเขตผู้ให้บริการ

ขั้นตอนนี้ไม่ลบหรือแก้ external LINE/Google account, provider credentials, Production owner LINE identity หรือ Production data การลบ B หมายถึง ChatGun UAT Google-linked identity/account เท่านั้น และต้องมีคำสั่งที่ถูกต้องแยกจาก consent ใช้ UAT
