ข้อมูลและวัตถุประสงค์

ประมวลผล OAuth provider/subject และ session, digest ของ private account reference, acceptance/version/time, โปรไฟล์, voluntary approximate location, Discovery, Direct text Chat/read state, opt-in Presence heartbeat/preference, blocks, reports, security/rate-limit/audit events และ deletion lifecycle เพื่อให้ UAT สองคน ทำความปลอดภัย แก้ defect และ cleanup ไม่ขายหรือใช้โฆษณา ไม่เก็บ credential หรือ raw invitation ใน GitHub

การทดสอบต่อเนื่อง

เมื่ออนุมัติแล้ว A/B อาจเข้าได้ตลอด 24 ชั่วโมง ข้อมูลและ provider-linked sessions จึงอาจถูกประมวลผลต่อเนื่องตามการใช้งานจนถอนความยินยอม ถูกเพิกถอน หรือเจ้าของปิด UAT อย่างชัดแจ้ง เวลา 19:00–22:00 เป็นเวลาผู้ดูแล ไม่ใช่ access window และไม่มี automatic shutdown รายงานนอกช่วงเข้าคิว ผู้เข้าร่วมต้องยินยอมเพิ่มต่อ always-on processing และรับทราบว่าไม่มี 24/7 human review

ความเสี่ยงและการควบคุม

ระยะ/เวลาอาจช่วยอนุมานพื้นที่ Chat ไม่เข้ารหัส end-to-end Presence ปิดเริ่มต้นและใช้ heartbeat ผู้เข้าร่วมปิด Discovery/Presence, block, report, revoke sessions, ถอนตัว หรือขอเข้าถึง/แก้ไข/ลบได้ การอนุญาตถูกจำกัดด้วย allowlist identity ฝั่งเซิร์ฟเวอร์, OAuth/Turnstile/MFA, cookies/CSRF, rate limits และ kill switch แต่ไม่มีความปลอดภัยหรือ uptime สมบูรณ์

ผู้ประมวลผลและข้อจำกัด

ข้อมูลแอปอยู่ใน Cloudflare D1 ของ UAT และผ่าน Pages/Workers; OAuth ผ่าน Google, Facebook หรือ LINE ตามที่เลือก R2 คง private, Production unchanged และ Media ปิด ไม่มี public registration, youth, Sensitive, OTP, Demo, automated scanning, independent age verification หรือ legal certification ผู้ดูแลหลักตรวจ 19:00–22:00 Asia/Bangkok ไม่มี backup moderator, emergency service, SLA หรือ 24/7 monitoring

Retention

ข้อมูลสดที่จำเป็นคงได้ขณะ UAT เปิด เมื่อ explicit close จะทำ logical cleanup ภายในเจ็ดวัน provider-linked sessions ถูกเพิกถอนและข้อมูลบัญชีจัดการตาม consent เก็บเฉพาะ minimized security/audit evidence 90 วันจาก actual close ไม่รวม Chat เต็ม พิกัด raw account reference credential Media หรือโปรไฟล์เพื่อใช้งานต่อ Cloudflare backup และ Time Travel อาจอยู่นานกว่าและการลบ logical ไม่รับประกัน physical erasure ภายในกรอบเดียวกัน Participant A ไม่ถูกลบบัญชีอัตโนมัติ; Participant B ลบได้เมื่อมี consent แยกและหลังออกจาก active enrollment
